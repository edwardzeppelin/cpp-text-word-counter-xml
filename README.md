# cpp-text-word-counter-xml

Text Word Frequency & XML Exporter
A lightweight C++ program that reads a plain text file, parses words while stripping punctuation, tracks word frequencies using a dynamic dictionary structure, sorts words alphabetically, and exports the statistics into an XML report.
Features:
- Custom Tokenization: Splits input text by whitespace and various punctuation marks.
- Dynamic Memory Management: Automatically resizes memory arrays to track unique word counts.
- Alphabetical Sorting: Sorts all discovered unique words alphabetically.
- XML Output: Writes word counts and overall statistics to result.xml.
